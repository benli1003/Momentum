# Momentum

Momentum is a cross-platform task and productivity app designed to help users efficiently manage their to-do lists with a clean, intuitive interface. 
The app leverages a SwiftUI frontend for iOS and a Django backend with RESTful API integration. This is a side project in which I learned more about
mobile app development and full-stack developement.

## 🚀 Features

- Create, update, and delete tasks
- Mark tasks as complete/incomplete
- Set and update due dates
- Secure JWT-based user authentication
- SwiftUI interface with real-time updates
- Backend API built with Django Rest Framework

## 🛠️ Tech Stack

**Frontend**  
- SwiftUI  
- Combine  
- URLSession / Codable  
- JWT Auth  

**Backend**  
- Django  
- Django REST Framework  
- MySQL
